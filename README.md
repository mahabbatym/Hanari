# Hanari — Корея мәдениеті

Оңтүстік Кореяның тарихы, дәстүрі, тағамы және тіл негіздерімен таныстыратын Flutter қосымшасы. 1-кезеңнің экран қаңқасы мен навигациясы және 2-кезеңнің мәдени материалдары жасалды.


## Құрылым

- `lib/screens` — экрандар, маршруттар және негізгі навигация
- `lib/widgets` — ортақ көрнекі компоненттер, соның ішінде күлтелер анимациясы
- `lib/models` — бөлім және профиль моделдері
- `lib/data` — жергілікті бөлім деректері мен дереккөздері
- `lib/services` — Supabase Auth және профиль деректеріне қатынау
- `supabase/migrations` — профиль кестесі, Auth триггері және RLS саясаты
- `lib/theme` — ортақ Hanari дизайн тақырыбы

Кіру мен тіркелу Supabase Auth арқылы орындалады. Тіркелген қолданушы профилі
`profiles` кестесіне Auth триггері арқылы жазылады; RLS әр қолданушыға тек
өз профилін оқуға және жаңартуға рұқсат береді.

## Жоспар құжаты: 2-сабақ — мәдени мазмұн

- Тарихқа хронология және жеке материал беттері қосылды
- Дәстүрлер карточкалар мен толық мәлімет беттерінде көрсетіледі
- Алты тағам сипаттамасымен, негізгі құрамдарымен және суретімен берілді
- Мәтін және сурет дереккөздері мен лицензиялары материалдармен бірге сақталады
- Сурет жүктелмесе, белгішелі балама көрсетіледі
- Басты беттен күннің дерегіне, ұсынылған материалға және тағамға өтуге болады

## TT_MVP: 2-кезең — Supabase Auth және профиль

- Supabase URL және publishable key іске қосу параметрлері арқылы оқылады
- Кіру мен тіркелу, аты/email/құпиясөз валидациясы және email растау күйі өңделеді
- Сессия қайта іске қосқанда тексеріліп, белсенді қолданушы басты бетке өтеді
- Профиль `profiles` кестесінен алынып, аты, email, avatar URL, тіл және тіркелген күні көрсетіледі
- Жүйеден шығу Supabase Auth сессиясын жояды
- `user_id = auth.uid()` RLS саясаты профиль жолын басқа қолданушылардан қорғайды
